# moon-mock 首版计划

## 首版设计

用独立 CLI 从指定 `.mbt` 源文件和 trait 名生成同包测试用的 `*_wbtest.mbt` 文件。生成结果是可审查的普通 MoonBit 源码。命令将提供标准输出和显式输出路径，并用检查模式发现 CI 中过期的生成文件。期望运行库与解析器分包，消费方测试只依赖运行库。

- **生成范围** 支持 `Self` 接收者、位置参数、必填标签 `label~` 与可省略标签 `label?`、同步及异步方法、返回值和有明确错误类型的 `raise`。方法和嵌套函数分别识别异步隐式错误效果与显式 `noraise`。带默认实现的方法生成显式覆盖，并沿用严格预期。参数和返回值可以是 trait 对象或函数。支持同文件及同包跨文件继承，菱形继承的公共祖先只生成一组预期。复杂泛型方法及跨包类型别名解析延后。无明确支持的签名要返回包含源码位置的诊断。
- **预期语义** 对每个方法生成类型化配置接口。首版支持返回值及抛错、精确或谓词匹配、精确次数、上下限或仅下限，以及显式顺序组。顺序组在前一步达到下限后允许前进。异步顺序以进入调用为准，预期在可能挂起的回调开始前记账。禁止共享可变的全局控制器。
- **自动核对** 用作用域入口在测试体返回前后收集未完成预期。测试体抛错时保留原错误，避免清理错误掩盖原失败。独立验收 `noraise`、异常和异步取消的行为后再冻结 API。
- **工具链** 已安装 `moon 0.1.20261028` / `moonc v0.10.18+6c83a7f62`。锁定官方 `moonbitlang/parser@0.4.7`（Apache-2.0）。`0.4.8` 在当前工具链与 `lexer@0.4.5` 组合中出现 E4018。首选 native CLI，生成代码与运行库以 native 和 JS 为验收目标。 [parser 0.4.7](https://mooncakes.io/docs/moonbitlang/parser%400.4.7)

## 阶段与验收

| 阶段 | 交付与退出条件 |
| --- | --- |
| 1 查重和可行性 | 公开候选、查重命令、差异与价值见 dedup.md。独立探针在 JS 和 native 各通过 2 项测试，涵盖 AST 的异步及错误效果字段，以及手写实现的 trait 分派、返回值和抛错。探针源码和命令输出保存在本地 `.probe/` 和 `docs/evidence/`。 |
| 2 生成器 | 固定解析器和 trait 子集。实现可复现代码生成，验证同一输入两次输出相同。每类签名用正例、拒绝用例和生成后实际编译来验证。 |
| 3 期望运行库 | 实现次数、匹配、返回、抛错和顺序，覆盖未调用、超次数、参数不符、顺序不符。同步和异步测试各验证作用域自动收尾。 |
| 4 生态样例和 CI | 数据库事务回滚与 HTTP 重试或任务执行两个独立案例，保留适配前后可比较的代码。CLI 生成后运行 `moon check` 和 `moon test`，检查生成物是否过期，配套中文文档。 |
| 5 发布 | 验证复现步骤，核对 Apache-2.0 和依赖署名，按阶段记录实质提交。个人提交及远程操作仅用 `dtzrttp`。仓库与申报材料分别处理。 |

阶段 1 验证在探针目录实际执行，JS 与 native 均为 2/2。

## 首版实现核对

- [x] `generator/signatures.mbt` 从官方 AST 提取签名和错误效果并报告不支持的位置。`generator/emit.mbt` 生成同包 mock 和类型化调用配置。
- [x] `runtime/` 提供参数匹配、控制器作用域、计数、显式顺序及错误报告。测试覆盖取消后关闭作用域，以及避免用验证错误覆盖原错误。
- [x] `cmd/moon-mock/` 支持标准输出、写文件和检查，与两份生成示例做 CLI 验收。
- [x] `examples/` 演示事务回滚和异步传输重试。独立 workspace 的消费方验收由 `tools/consumer-smoke.mjs` 复现。
- [x] `.github/workflows/ci.yml` 配置 JS 和 native 验证。

## 2026-11-22 初审后扩展

- [x] 继承方法冲突同时报告两处声明，增加128层继承边界，验证辅助文件顺序不影响输出。
- [x] 添加组合、否定、集合及投影匹配器，以及成功选择后记录参数的 Capture。控制器提供计数快照与版本化 JSON。
- [x] 为登记和计数构造增加可处理的 Result API，并禁止不同控制器混用顺序组。已有严格登记接口保持可用。
- [x] 把实际值诊断推迟到匹配失败后构造。固定种子的参考模型对照32000次调用，另外覆盖96种签名组合、60个损坏输入、32个协作异步任务和整数计数上界。
- [x] 在固定版本的 Exa 和 moondb 中扩充真实客户端、事务、游标及预处理语句接入测试，更新固定输入的来源和许可。
- [x] 本地发行 ZIP 解压后在全新消费方构建与运行，native 验证安装到临时 bin。CI 加入两后端打包消费方验收和微基准编译。
- [x] 提供六个真实接口与三个合成接口的双后端 CLI 基准脚本，以及运行库和生成器微基准。原始样本与复现方法见 benchmarks。
