# 验证范围与复现

2026-11-22 的本地验证使用固定编译器 `moonc v0.10.18+6c83a7f62`，覆盖 JS 与 Windows native。普通项目测试与微基准分开执行，基准不会增加普通测试的通过数量。

| 范围 | 每个后端的实际结果 | 复现 |
| --- | --- | --- |
| 项目测试 | 52/52 | `moon test --target js --deny-warn` 或 `--target native` |
| CLI 验收 | 18 个命令 | `node tools/cli-smoke.mjs js` 或 `native` |
| 独立消费方 | 9/9 | `node tools/consumer-smoke.mjs js` 或 `native` |
| 发行 ZIP 的全新消费方 | 9/9 | `node tools/package-smoke.mjs js` 或 `native` |
| Exa SDK 固定版本接入 | 2/2 | 见 adoption.md |
| moondb 固定版本接入 | 5/5 | 见 adoption.md |

消费方脚本须先构建对应目标的 CLI。打包脚本自行创建 ZIP，并在新目录验证发行包构建。native 打包脚本进一步安装 CLI 到临时 bin 后运行帮助命令。ZIP 检查覆盖 LICENSE、清单、缓存排除和路径越界。发行包测试与源码消费方有相同的九项业务测试，表中分别记录两种分发方式。

## 参考模型和变更测试

- `runtime/model_test.mbt` 为64个固定种子分别登记24条区间预期，然后进行300次调用，总计19200次，与独立数组模型对照选择结果、错误码、上下限和实际次数。
- 同文件另用32个固定种子构造16步顺序组，每个进行400次调用，共12800次，对照顺序游标、次数上限和可选步骤。
- `generator/robustness_test.mbt` 构造同步/异步、标签/位置参数、六类参数与四类返回的96种签名，检查确定性输出。60次损坏输入后均接着生成合法接口，验证错误不会污染下次调用。
- 菱形继承的辅助文件排列变化应得到相同源码。循环和缺失父 trait 返回可定位诊断。同名方法冲突须包含两个声明的位置。

以上方法属于固定种子的参考模型测试与输入变更测试。它们覆盖明确列出的状态组合，持续的覆盖率引导模糊测试仍是后续工程方向。

## 生命周期和极值

- 可选次数、零次禁止、区间上下限、无上限、Int32 上界计数饱和。
- 参数不符、调用过多和顺序阻塞均不会记录捕获。或组合只通知实际选中的分支。
- 32个异步协作任务共享方法，选择及计数发生在回调挂起前。错误、取消和关闭作用域继续沿用原来的传播规则。
- 控制器登记失败不改变已有预期或序列。跨控制器共享顺序组会被明确拒绝。
- 128层继承限制、空/损坏声明、非法生成类型名、辅助源码语法错误及对应来源位置。
- Unicode、引号和换行可通过标准 JSON 编码输出。统计快照和捕获数组副本不随之后的计数或数组修改而变化。

## 已知验证边界

JS 与 native 均覆盖协作式异步执行。操作系统多线程共享 mock 的同步语义尚未支持。moondb 自身使用较新的 `#derive`，接入用隔离的0.10.20编译器运行，并接受本运行库两条旧式 derive 弃用警告。Windows native 的上游 async C 文件会产生 EINVAL 宏重定义警告。

真实项目接入固定了源码版本，验证的是使用方业务调用和生成的替身是否互相兼容。外部接口的长期网络服务可用性不属于这组离线测试的验收条件。
