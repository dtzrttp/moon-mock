## 运行库变更前后

基线采用 `5ad8047` 的运行库，使用本次新增的相同基准场景。变更后为 `b402907` 的运行库，包含组合匹配、捕获回调、控制器隔离和延迟诊断。下表为10组自适应重复的均值，标准差、范围和实际重复次数保留在原始文本。

| 场景 | JS 变更前 → 后 | native 变更前 → 后 |
| --- | --- | --- |
| 1条预期末尾匹配 | 11.16 → 11.51 ns | 87.38 → 80.43 ns |
| 32条预期末尾匹配 | 210.59 → 120.52 ns | 834.48 → 334.88 ns |
| 256条预期末尾匹配 | 2.49 → 1.16 μs | 2.53 → 1.98 μs |
| 首条预期匹配 | 11.66 → 10.96 ns | 90.41 → 83.59 ns |
| 参数失败诊断 | 119.24 → 129.42 ns | 841.29 → 799.04 ns |
| 新建并完成32步顺序调用 | 9.78 → 8.90 μs | 45.83 → 32.48 μs |

成功匹配后续预期时，变更后把实际值的字符串诊断推迟到最终失败分支。回归测试单独验证成功路径不会调用诊断渲染器。失败诊断的 JS 均值有所增加，单条路径也存在小幅波动。当前实现仍线性扫描预期，数据没有表明扫描复杂度发生变化。
