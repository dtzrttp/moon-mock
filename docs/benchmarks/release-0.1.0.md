[完整原始样本](cli-release-0.1.0.json) 保留环境、源码提交、脚本哈希、输入来源及许可证、输入输出哈希。与[上一批198个样本](2026-11-22.md)合计保存396个CLI进程计时样本，其中264个来自真实接口；它们是两批各自独立的数据，不把22个样本重新混算成一个分布。真实业务接入结果见[生态适配](../adoption.md)。

复现：先执行 `moon build --target js --release --deny-warn` 与 `moon build --target native --release --deny-warn`，再执行 `node tools/benchmark.mjs --real --samples=11`。输入下载首次需要网络，已缓存的固定版本可离线复测。系统负载、GC及电源状态会影响结果；未作跨机器或性能阈值承诺。
